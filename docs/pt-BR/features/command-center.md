# Acesso Rápido

O campo de pesquisa centralizado na barra de título oferece acesso rápido a arquivos, comandos, símbolos e navegação por linha. Clique no campo para dar foco e abrir sugestões. Use os botões de seta ao lado para voltar ou avançar pelo histórico de navegação do editor.

Digite normalmente para pesquisar arquivos por correspondência aproximada em todas as raízes do workspace. Use o prefixo `>` para pesquisar e executar comandos, `#` para pesquisar símbolos em todo o workspace, `@` para pesquisar símbolos no arquivo ativo ou `:` para ir a uma linha iniciada em 1 ou a `linha:coluna`. O campo e a lista de sugestões aceitam seleção pelas setas, Enter para abrir ou executar o item selecionado e Esc para fechar. Atalhos existentes, como Ctrl+P, Ctrl+Shift+P, Ctrl+T, Ctrl+Shift+O e Ctrl+G, continuam disponíveis.

O campo fica centralizado na janela; quando necessário, os menus excedentes vão para **Mais** para manter separados o campo, os botões de navegação e os controles da janela. Os rótulos e nomes acessíveis estão disponíveis em inglês e português brasileiro.

# v0.3 — Servidores de linguagem e terminal integrado

## Language Server Protocol

O app inicia executáveis LSP instalados pelo usuário por stdio, um servidor para cada extensão configurada. Os processos rodam fora do loop da janela. Notificações de abertura, alteração, salvamento e fechamento são enviadas por documento, com posições UTF-16 e alterações incrementais quando solicitadas pelo servidor. Diagnósticos ficam associados a cada aba e resultados versionados antigos são ignorados.

Os comandos disponíveis são autocomplete (`Ctrl+Espaço`, depois Enter ou Tab), ir à definição (`F12`), hover (`Ctrl+K`, depois `Ctrl+I`) e navegação por diagnósticos (`F8` / `Shift+F8`). Os diagnósticos aparecem no painel Problemas (`Ctrl+Shift+M`). Servidores ausentes ou que falharem informam o estado, e a edição continua disponível.

Crie `lsp.json` na pasta de configuração do Graphite. No Windows, ela fica em `%APPDATA%\Graphite`; no Linux, em `$XDG_CONFIG_HOME/Graphite`, com fallback para `~/.config/Graphite`.

```json
{
  "servers": [
    {
      "extension": "rs",
      "languageId": "rust",
      "command": "rust-analyzer",
      "args": []
    }
  ]
}
```

`extension` é comparada sem ponto inicial. `command` é o nome ou caminho do executável, e `args` são passados como argumentos separados. Adicione uma entrada para cada associação entre extensão e servidor. O app não baixa nem instala servidores.

## Terminal integrado

Alterne o painel inferior com `Ctrl+grave`. Clique na aba Terminal para dar foco ao shell e na aba Problemas para consultar diagnósticos. O terminal inicia na raiz do workspace e mantém o processo ativo enquanto está oculto. Ele suporta cores ANSI, teclas comuns de navegação, entrada UTF-8, histórico de rolagem e redimensionamento. No Windows, usa PowerShell por padrão; no Linux, usa `$SHELL` ou `sh` como fallback.

Para escolher outro shell, defina `GRAPHITE_SHELL` ou crie `terminal.json` na mesma pasta de configuração:

```json
{ "shell": "C:\\Program Files\\PowerShell\\7\\pwsh.exe" }
```

A variável de ambiente tem prioridade. Nesta versão, `terminal.json` contém somente o caminho do executável; argumentos do shell não são configuráveis.

## Escopo

O cliente LSP suporta servidores stdio, sincronização de texto, diagnósticos, autocomplete, definição e hover. O terminal usa PTY nativo e o parser/grade de terminal do Alacritty. Instalação automática de servidores, depuração e suporte ao extension host ficam fora da v0.3.

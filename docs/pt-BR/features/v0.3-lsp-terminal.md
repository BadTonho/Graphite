# v0.3 — Serviços de linguagem, navegação e terminal

## Language Server Protocol

O app inicia servidores de linguagem instalados pelo usuário via stdio, um para cada extensão configurada. Os processos do servidor e a validação JSON Schema rodam em workers fora da interface. Notificações de abertura, alteração, salvamento e fechamento são enviadas por documento com posições UTF-16; alterações incrementais são usadas quando solicitadas pelo servidor. Diagnósticos versionados antigos são ignorados.

Configure os servidores em `lsp.json` na pasta de configuração do Graphite. No Windows, ela fica em `%APPDATA%\Graphite`; no Linux, em `$XDG_CONFIG_HOME/Graphite`, com fallback para `~/.config/Graphite`. Se a pasta Graphite não existir, mas a pasta anterior `VsCodeShoppe` existir, o app continua usando a pasta anterior. Se ambas existirem, Graphite tem prioridade.

```json
{
  "servers": [
    {
      "extension": "rs",
      "languageId": "rust",
      "command": "rust-analyzer",
      "args": []
    }
  ]
}
```

`extension` é comparada sem ponto inicial. `command` é o nome ou caminho do executável, e `args` são passados separadamente. O app não baixa nem instala servidores.

Use `Ctrl+Espaço` para obter conclusões; aceite uma sugestão com Enter ou Tab. Ir à definição usa `F12`; hover usa `Ctrl+K` e depois `Ctrl+I`. `F8` / `Shift+F8` percorrem diagnósticos de todos os documentos abertos. `Ctrl+Shift+M` abre o painel Problemas, que combina diagnósticos do servidor de linguagem e do JSON Schema. `Ctrl+.` abre as ações Quick Fix disponíveis; use Setas para escolher, Enter para aplicar e Esc para fechar. Alterações do workspace respeitam documentos somente leitura e os limites do workspace. Erros do servidor são exibidos na barra de status, e a edição continua disponível.

Inlay hints são exibidos quando o servidor configurado oferece suporte. A busca por hints e ações Quick Fix é assíncrona.

## Schemas JSON e JSONC

Adicione uma propriedade `$schema` a um documento JSON ou JSONC. O valor pode ser um caminho relativo ao documento, um URI `file://` ou uma URL HTTPS. Schemas remotos e referências HTTPS são armazenados em cache na pasta de configuração do app, dentro de `schema-cache`. O editor valida os documentos e sugere nomes de propriedades ainda não usadas, além de valores `enum` e `const`; referências `$ref` locais e externas são consultadas para as conclusões.

JSON inválido, schemas, referências e falhas de rede aparecem como diagnósticos e não interrompem a edição. A busca remota aceita somente HTTPS.

## Navegação e contexto

Sticky Scroll mantém declarações ancestrais no topo do editor durante a rolagem, usando os escopos de declaração da árvore de sintaxe do tree-sitter. `Alt+Seta Esquerda` / `Alt+Seta Direita` percorrem o histórico do cursor; `Ctrl+Tab` e `Ctrl+Shift+Tab` alternam entre documentos usados recentemente; `Ctrl+Shift+T` reabre a última aba fechada.

## Snippets do projeto

O app carrega snippets compartilhados em `.vscode/*.code-snippets`. O campo `scope` aceita uma string separada por vírgulas ou uma lista; os identificadores de linguagem suportados incluem `rust`, `python`, `javascript` e `json`. Snippets do projeto têm prioridade sobre snippets globais com o mesmo prefixo e escopo. Arquivos inválidos são reportados sem impedir o carregamento dos demais snippets.

## Terminal integrado

Alterne o painel inferior com `Ctrl+grave`. O terminal inicia na raiz do workspace e aceita cores ANSI, entrada pelo teclado, texto UTF-8, histórico de rolagem e redimensionamento. Várias sessões podem permanecer abertas. A barra do painel cria sessões, divide o espaço e fecha a sessão focada; clique em uma aba para selecioná-la. Os controles `<` e `>` percorrem as abas que não cabem na barra.

Os perfis padrão são PowerShell, Prompt de Comando e WSL no Windows. No Linux, os perfis são `$SHELL` (com fallback para `sh`), Bash e zsh. Defina `GRAPHITE_SHELL` para substituir todos os perfis configurados ou crie `terminal.json` na pasta de configuração do app:

```json
{
  "defaultProfile": "PowerShell",
  "profiles": {
    "PowerShell": { "path": "powershell.exe", "args": ["-NoLogo"] },
    "Prompt de Comando": { "path": "cmd.exe", "args": [] },
    "WSL": "wsl.exe"
  }
}
```

Cada perfil aceita um caminho em formato de string ou um objeto com `path` e `args`. O formato legado `{ "shell": "..." }` continua válido. `GRAPHITE_SHELL` tem prioridade sobre a antiga `VSCODESHOPPE_SHELL`, e ambas têm prioridade sobre `terminal.json`; `defaultProfile` seleciona um perfil nomeado quando há perfis configurados. Variáveis de ambiente vazias são ignoradas.

## Escopo e verificação

O terminal usa PTY nativo e a grade/parser de terminal do Alacritty. Instalação automática de servidores, depuração e suporte ao extension host ficam fora da v0.3. Testes automatizados, build do workspace e formatação no Windows estão registrados no roadmap. A interação com a janela nativa continua pendente; Linux não foi testado nesta rodada.

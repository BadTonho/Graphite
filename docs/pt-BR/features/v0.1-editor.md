# v0.1 — Editor Base

## Funcionalidades

- Abrir uma pasta (`shoppe-app -- <pasta>`); árvore lateral que respeita o `.gitignore`, diretórios primeiro, `.git` oculto.
- Clicar em uma pasta expande/recolhe; clicar em um arquivo o abre.
- Edição de texto: inserir, Backspace, Delete, Enter, Tab (exibido como 4 espaços), setas, Home, End, posicionar cursor com o mouse, rolagem com a roda.
- Números de linha, cursor, barra de status (arquivo, marcador de alterações, linha/coluna).
- `Ctrl+S` salva o arquivo atual.
- Highlighting para Rust, Python, JavaScript e JSON (pela extensão).

## Onde fica

| Funcionalidade | Crate |
|---|---|
| Buffer, cursor, salvar/carregar | `shoppe-text` |
| Listagem de pastas | `shoppe-workspace` |
| Highlighting | `shoppe-syntax` |
| Desenho na GPU e texto | `shoppe-render` |
| Janela, árvore, UI do editor | `shoppe-app` |

## Testes

`cargo test --workspace` cobre o buffer, a listagem do workspace, o empacotador do atlas e o highlighter. O comportamento da UI (renderização, entrada) só passou por um teste de inicialização e precisa de verificação manual.

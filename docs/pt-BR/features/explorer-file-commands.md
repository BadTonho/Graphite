# Comandos do explorador e de arquivos

| Comando | O que faz |
| --- | --- |
| Novo arquivo... / Nova pasta... (no explorador) | Pede um nome e cria a entrada dentro da pasta selecionada, ao lado do arquivo selecionado, ou na pasta do espaço de trabalho quando nada está selecionado. Um nome com pastas (`a/b/c.txt`) cria as pastas também. O novo arquivo abre no editor. Nomes vazios, absolutos, que saem da pasta (`..`) ou que já existem são recusados com uma mensagem. |
| Atualizar o explorador | Lê as pastas do disco de novo, para aparecerem arquivos criados fora do Graphite. |
| Recolher pastas no explorador | Recolhe todas as pastas. |
| Abrir arquivo mantendo o foco no explorador | Abre o arquivo selecionado como aba de pré-visualização e deixa o foco do teclado no explorador. |
| Copiar o caminho do arquivo ativo | Copia o caminho completo do arquivo do editor ativo. |
| Novo arquivo de texto sem título | Abre uma nova aba vazia (também pelo comando da barra de abas). |
| Fechar todos os editores | Fecha todas as abas, mantendo as que têm alterações não salvas. |
| Alternar layout vertical/horizontal dos editores | Inverte a direção em que os grupos de editores são dispostos. |

Ainda não há recortar e colar no explorador, então os comandos que cancelam um recorte não estão disponíveis.

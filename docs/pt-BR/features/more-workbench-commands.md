# Mais comandos do workbench

| Comando | O que faz |
| --- | --- |
| Mover a barra de atividades para o lado / topo / baixo, Ocultar a barra de atividades | Define a posição da barra de atividades; a escolha é salva com o perfil. |
| Alternar trilha de navegação / Mostrar trilha de navegação | Inverte ou liga a trilha de navegação (breadcrumbs). |
| Copiar caminho da trilha de navegação | Copia o caminho completo do arquivo do editor ativo para a área de transferência. Indisponível para um editor sem arquivo. |
| Nova janela | Abre outra janela do Graphite no mesmo espaço de trabalho. |
| Limpar histórico de editores (e sem confirmação) | Esquece os editores usados recentemente, o histórico de navegação para trás e para frente e a lista de abas fechadas que podem ser reabertas. Não há etapa de confirmação. |
| Reverter e fechar o editor | Recarrega o arquivo do disco e fecha a aba dele. Um arquivo com alterações não salvas pede confirmação antes e continua aberto até você responder. |
| Duplicar grupo de editores à esquerda / direita / acima / abaixo | Divide um novo grupo nesse lado com uma cópia de todas as abas, mantendo a mesma aba ativa. |

A trilha de navegação só mostra o caminho por enquanto, então os comandos que focam, percorrem ou escolhem itens dela não estão disponíveis.

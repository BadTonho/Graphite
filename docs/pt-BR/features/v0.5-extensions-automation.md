# v0.5 — Extensões e Automação

A Fase 5 está em andamento. Esta página registra os limites atuais para que o roadmap não sugira compatibilidade completa com o VS Code.

## Bases disponíveis

- A paleta nativa abre com `Ctrl+Shift+P` ou `F1`, filtra comandos registrados pelo Graphite e pelo host ativo e impede a execução de comandos desabilitados.
- A confiança do workspace é concedida explicitamente e persistida usando o caminho canônico. `Confiar neste workspace` concede a confiança; `Revogar confiança do workspace` a remove e encerra os hosts de plugins ativos. A ativação de plugins nativos Graphite continua exigindo a confiança adicional para cada versão.
- Um cliente local do registro Open VSX oferece busca, metadados da versão mais recente e downloads VSIX limitados. As respostas são validadas, os downloads exigem HTTPS fora dos fixtures de loopback e os arquivos passam pelo inspetor VSIX existente antes da instalação.
- As primitivas de configuração de tarefas analisam entradas `shell` e `process`, argumentos, diretórios de trabalho, grupo padrão de build e capturas regex nomeadas. O executor exige confiança do workspace e oferece cancelamento e callback para transmitir saída.
- O editor expande um subconjunto de abreviações HTML/JSX e CSS com `Tab` e pelo comando `Emmet: Expandir abreviação`.
- As primitivas de armazenamento de perfis criam diretórios isolados e copiam configurações existentes para `Default` sem remover os arquivos legados.

## Limitações atuais

O host de extensões Code OSS 1.145.2 e a ponte de compatibilidade para `commands`, `workspace`, `window` e `languages` ainda não foram integrados. Busca e download Open VSX estão expostos como API de biblioteca; a barra de plugins ainda não instala nem ativa pacotes VSIX. O runtime de plugins nativos Graphite permanece separado.

As tarefas ainda não estão ligadas à paleta de comandos, a `Ctrl+Shift+B`, à interface do terminal nem aos diagnósticos do painel Problems. A implementação Emmet atual é um pequeno subconjunto local, não a implementação upstream fixada. O armazenamento de perfis ainda não está conectado a configurações, temas, atalhos, snippets nem à troca do ciclo de vida dos hosts. Essas lacunas mantêm abertos todos os itens da Fase 5.

As verificações automatizadas usam dados locais e não acessam um marketplace. Testes da aplicação e do crate de plugins foram executados no Windows durante o desenvolvimento; as verificações finais de aceitação do workspace ainda estão pendentes. Linux não foi testado nesta rodada.

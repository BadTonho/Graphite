# v0.5 — Extensões e Automação

A Fase 5 continua em andamento. A implementação não declara compatibilidade geral com extensões do VS Code até que o host Code OSS fixado e sua ponte Rust do lado principal sejam integrados e validados.

## Fundamentos implementados

- A paleta filtra comandos nativos do Graphite, comandos de plugins Graphite ativos e tarefas configuradas no workspace. As tarefas mostram sua origem e não podem ser executadas antes de confiar no workspace. `Ctrl+Shift+B` seleciona a tarefa de compilação padrão.
- `tasks.json` aceita tarefas `shell` e `process` com rótulos, argumentos, diretórios de trabalho, grupos de compilação padrão e problem matchers por expressões regulares. As tarefas rodam fora da thread da interface, transmitem a saída ao painel de terminal, aceitam cancelamento e publicam diagnósticos para arquivos abertos que correspondem ao matcher.
- A confiança do workspace é opcional e persistida usando o caminho canônico do workspace. A ativação de plugins nativos Graphite exige também confiança explícita para cada versão.
- A barra de Plugins pesquisa no Open VSX, baixa a versão VSIX mais recente em um worker, inspeciona o arquivo e pede confirmação antes de instalar. O cliente exige HTTPS, confere a identidade e limita os downloads. VSIX instalados permanecem inativos até a integração do host Code OSS.
- O Emmet usa o pacote upstream `emmet` 2.4.11, incluído com sua licença MIT e acessado por um worker Node persistente. `Tab` e `Emmet: Expand Abbreviation` usam a mesma implementação upstream.
- Perfis persistem a seleção ativa e oferecem comandos para criar, listar e trocar. Cada perfil tem configurações, tema, atalhos, snippets, configurações de terminal e loja de plugins próprios; o estado antigo é copiado para `Default` sem apagar os arquivos originais. A troca recarrega essas configurações e encerra os hosts de extensão do perfil.

## Trabalho restante da Fase 5

O host Code OSS 1.145.2 (`c4453f8`) ainda não está integrado nem empacotado. O auxiliar atual em Rust usa um protocolo Graphite e não ativa extensões VSIX. Ainda faltam a ponte Rust para as APIs públicas de `commands`, `workspace`, `window` e `languages`, o ciclo de vida sob demanda do host Code OSS, a confiança específica por extensão e a ativação VSIX local.

O modo de confiança do workspace bloqueia tarefas e ativação de plugins nativos; a ativação de extensões Code OSS ainda precisa dessa barreira. Os dados de perfil já são isolados e trocados por comandos, enquanto a integração do ciclo de vida dos hosts VSIX continua pendente.

Essas lacunas mantêm a Fase 5 aberta. Os testes do marketplace usam uma fixture HTTP local, sem acessar o serviço público. Os testes Windows foram executados nesta rodada; Linux e validação visual nativa não foram realizados.

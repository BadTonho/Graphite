# v0.2 — Edição e personalização

## Interações disponíveis

- Selecione texto com o mouse ou `Shift` + navegação; `Ctrl+A` seleciona o buffer. `Ctrl+C/X/V` usam a área de transferência do sistema; `Ctrl+Z/Y` desfazem e refazem.
- Abra arquivos em abas, alterne com `Ctrl+Tab` e feche com `Ctrl+W`. Uma aba alterada pergunta se deve salvar, descartar ou cancelar.
- `Ctrl+F` busca no workspace, respeita arquivos de exclusão e permite navegar pelos resultados com as setas; Enter abre o resultado selecionado.
- `Ctrl+Alt+T` alterna e persiste a paleta clara/escura incluída. `Ctrl+Shift+I` importa configurações, snippets e temas JSON suportados do VS Code para a pasta de configuração do Graphite.
- `Ctrl+Shift+P` filtra prefixos de snippets importados; Enter insere o resultado selecionado.
- Texto confirmado por IME é inserido pelos eventos do winit. A janela expõe uma árvore AccessKit para o editor e as abas.

## Configurações importadas suportadas

`editor.fontSize`, `editor.tabSize`, `editor.insertSpaces`, `workbench.colorTheme` e as chaves suportadas de cores do editor/sidebar/barra de status são aplicados. `tokenColors` de temas para keywords, funções, tipos, strings, números, comentários e variáveis são mapeados para as classes de sintaxe. Outras configurações são reportadas como ignoradas. Arquivos importados são copiados; os originais não são alterados. A busca procura texto literal e ignora arquivos ilegíveis. Tab stops de snippets são substituídos pelo texto padrão; escolhas e variáveis não são expandidas.

Cada aba possui seu próprio parser e árvore tree-sitter. Edições são aplicadas à árvore e o realce é recalculado a partir do nó sintático que contém a mudança até o fim do arquivo; linhas anteriores inalteradas e abas inativas mantêm o cache. A árvore acessível expõe a lista de abas e o editor; tecnologia assistiva pode ativar abas, focar o editor, substituir seu valor e definir uma seleção.

## Verificação

Execute `cargo test --workspace` e `cargo check --workspace`. Verifique manualmente entrada, clipboard, abas, busca, temas, importação e leitor de tela no Windows e Linux.

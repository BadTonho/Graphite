# Navegação por teclado em listas

O explorador pode ser usado pelo teclado. Clique em uma entrada (ou rode **Focar a barra lateral primária**) para dar o foco a ele, e então:

| Tecla | Comando | O que faz |
| --- | --- | --- |
| `Cima` / `Baixo` | Focar o item anterior / próximo | Move a seleção. O primeiro movimento seleciona a primeira entrada. |
| `PageUp` / `PageDown` | Focar o item uma página acima / abaixo | Move de uma tela inteira. |
| `Home` / `End` | Focar o primeiro / último item | Vai para a primeira ou a última entrada. |
| `Direita` | Expandir | Expande a pasta selecionada; numa pasta já expandida, vai para a primeira entrada dela. |
| `Esquerda` | Recolher | Recolhe a pasta selecionada; num arquivo ou numa pasta recolhida, vai para a pasta pai. |
| `Enter` | Selecionar | Abre o arquivo selecionado como aba de pré-visualização, ou alterna a pasta selecionada. |
| `Espaço` | Alternar expansão | Alterna a pasta selecionada. |

Outros comandos sem tecla padrão: **Focar o item pai**, **Recolher tudo**, **Selecionar e manter o foco**, **Rolar para cima / baixo** (move a lista uma linha) e as variantes "qualquer lista" dos comandos de foco.

A entrada selecionada fica destacada enquanto o explorador tem o foco, e a lista rola para mantê-la à vista. Com o abrir rápido aberto, Cima, Baixo, Page Up / Down, Home e End percorrem os resultados dele.

Só o explorador e o abrir rápido são cobertos. Resultados de busca, a lista do controle de código-fonte e as outras listas ainda não respondem a esses comandos, e não há busca por digitação nem seleção múltipla.

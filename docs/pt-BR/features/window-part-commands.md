# Comandos das partes da janela

Comandos para as partes da janela: as barras laterais, o painel e o foco do teclado. Estão na paleta de comandos.

| Comando | O que faz |
| --- | --- |
| Fechar barra lateral primária / Fechar painel / Fechar barra lateral secundária | Esconde essa parte. A escolha é salva com as outras preferências de exibição. |
| Focar a barra lateral primária | Mostra a barra lateral se estiver escondida e leva o foco do teclado para ela. |
| Focar o painel | Mostra o painel com o terminal e leva o foco do teclado para ele. |
| Focar a próxima parte / Focar a parte anterior | Move o foco entre o editor, o terminal e a barra lateral, o mesmo ciclo de `F6` e `Shift+F6`, e diz para onde foi. |
| Próxima / anterior vista da barra lateral primária | Alterna entre Explorador, Busca, Controle de código-fonte e Extensões, nessa ordem, dando a volta. Vistas escondidas da barra de atividades são puladas, e uma barra lateral escondida é mostrada antes. |
| Alternar tela cheia | Igual à entrada do menu Exibir. |
| Alternar layout centralizado | Igual a Alternar editor centralizado. |
| Personalizar layout | Abre o popup de personalização do layout. |
| Sobre | Abre a janela Sobre. |
| Voltar / Anterior nos locais de navegação, Avançar nos locais de navegação | A mesma navegação de histórico de Voltar e Avançar, sob os outros ids de comando. |

A barra de atividades, a barra de status e as vistas do próprio painel (problemas, saída, console de depuração) ainda não têm foco de teclado próprio, então os comandos que as focariam não estão disponíveis.

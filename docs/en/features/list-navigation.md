# Keyboard navigation of lists

The explorer can be used from the keyboard. Click an entry (or run **Focus into Primary Side Bar**) to give it the focus, then:

| Key | Command | What it does |
| --- | --- | --- |
| `Up` / `Down` | Focus Previous / Next Item | Moves the selection. The first move selects the first entry. |
| `PageUp` / `PageDown` | Focus Item a Page Up / Down | Moves by one screenful. |
| `Home` / `End` | Focus First / Last Item | Jumps to the first or last entry. |
| `Right` | Expand | Expands the selected folder; on an expanded folder moves to its first entry. |
| `Left` | Collapse | Collapses the selected folder; on a file or a collapsed folder moves to the parent folder. |
| `Enter` | Select | Opens the selected file as a preview tab, or toggles the selected folder. |
| `Space` | Toggle Expand | Toggles the selected folder. |

Other commands without a default key: **Focus Parent**, **Collapse All**, **Select and Preserve Focus**, **Scroll Up / Down** (moves the list by one row), and the "any list" variants of the focus commands.

The selected entry is highlighted while the explorer has the focus, and the list scrolls to keep it in view. While quick open is open, Up, Down, Page Up / Down, Home and End move through its results instead.

Only the explorer and quick open are covered. Search results, the source control list and the other lists are not reachable through these commands yet, and there is no type-to-find or multi-selection.

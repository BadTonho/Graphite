# Command Center

The centered search field in the custom title bar provides quick access to files, commands, symbols, and line navigation. Click the field to focus it and open suggestions. Use the arrow buttons beside it to move backward or forward through editor navigation history.

Type normally to fuzzy-search files in every workspace root. Prefix a query with `>` to search and run commands, `#` to search symbols across the workspace, `@` to search symbols in the active file, or `:` to go to a one-based line or `line:column`. The field and its suggestion list support arrow-key selection, Enter to open or run the selected item, and Escape to close. The existing shortcuts such as Ctrl+P, Ctrl+Shift+P, Ctrl+T, Ctrl+Shift+O, and Ctrl+G remain available.

The search field is centered in the window, while menus overflow into **More** when needed to keep the field, navigation buttons, and window controls separate. Labels and accessible names are available in English and Brazilian Portuguese.

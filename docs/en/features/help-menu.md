# Help menu

The Help menu provides Graphite's local getting-started and diagnostic surfaces:

- **Welcome** opens files or folders and reopens recent workspaces.
- **Show All Commands** opens the command palette.
- **Editor Playground** creates an editable untitled document from a Rust or JavaScript sample.
- **Open Walkthrough** guides you through opening a workspace, editing, Source Control, and plugins.
- **Show Release Notes** displays the release notes bundled with this build.
- **Keyboard Shortcuts Reference** filters the built-in shortcut reference as you type. Edit profile overrides in **File → Preferences → Keyboard Shortcuts**.
- **Toggle Developer Tools** shows local application and workspace diagnostics in Graphite.
- **Open Process Explorer** opens the existing local process monitor.
- **Up to Date** is a compact placeholder until update checking is implemented. It does not check for or install updates yet.
- **About** displays the application version and MIT license.

Help pages open in an accessible modal over the editor and close with `Esc` or a click outside the dialog. All labels and page copy are available in English and Brazilian Portuguese. No remote documentation, account, or update service is contacted.

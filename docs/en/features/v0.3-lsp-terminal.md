# v0.3 — Language services, navigation and terminal

## Language Server Protocol

The app launches user-installed language servers over stdio, one server per configured file extension. Server processes and JSON Schema validation run on background workers. Open, change, save and close notifications are sent per document with UTF-16 positions; incremental changes are used when requested by the server. Stale versioned diagnostics are ignored.

Configure servers in `lsp.json` under the Graphite application configuration directory. On Windows this is `%APPDATA%\Graphite`; on Linux it is `$XDG_CONFIG_HOME/Graphite`, falling back to `~/.config/Graphite`. The application always uses this directory. Copy any existing settings stored elsewhere into it before launching Graphite.

```json
{
  "servers": [
    {
      "extension": "rs",
      "languageId": "rust",
      "command": "rust-analyzer",
      "args": []
    }
  ]
}
```

`extension` is matched without a leading dot. `command` is the executable name or path, and `args` are passed separately. The app does not download or install servers.

Completion uses `Ctrl+Space`; accept a suggestion with Enter or Tab. Go to definition uses `F12`, hover uses `Ctrl+K` then `Ctrl+I`, and `F8` / `Shift+F8` move through diagnostics from all open documents. `Ctrl+Shift+M` opens the Problems panel, which combines language-server and JSON Schema diagnostics. `Ctrl+.` opens available Quick Fix actions; use Up/Down to choose, Enter to apply, and Esc to close. Workspace edits respect read-only documents and workspace boundaries. Server errors are shown in the status area while editing remains available.

Inlay hints are displayed when the configured language server supports them. Hint display and Quick Fix actions are requested from the server asynchronously.

## JSON and JSONC schemas

Add a `$schema` property to a JSON or JSONC document. The value can be a path relative to the document, a `file://` URI, or an HTTPS URL. Remote schemas and their HTTPS references are cached under the application configuration directory in `schema-cache`. The editor validates documents and offers unused property names plus `enum` and `const` values; local and external `$ref` definitions are followed for completion.

Invalid JSON, schemas, references and network requests appear as diagnostics. They do not stop editing. Remote retrieval is limited to HTTPS.

## Navigation and context

Sticky Scroll keeps enclosing declarations at the top of the editor while scrolling. It uses declaration scopes from the tree-sitter syntax tree. `Alt+Left` / `Alt+Right` navigate cursor history; `Ctrl+Tab` and `Ctrl+Shift+Tab` switch through recently used documents; `Ctrl+Shift+T` reopens the last closed tab.

## Project snippets

The app loads shared snippets from `.vscode/*.code-snippets`. A snippet may use a comma-separated string or array in `scope`; supported language identifiers include `rust`, `python`, `javascript` and `json`. Project snippets take precedence over global snippets with the same prefix and scope. Invalid snippet files are reported without preventing other snippets from loading.

## Integrated terminal

Toggle the bottom panel with `Ctrl+grave`. The terminal starts in the workspace root and supports ANSI colors, keyboard input, UTF-8 text, scrollback and resize. Multiple sessions can stay open at once. The panel toolbar creates sessions, splits the panel and closes the focused session; clicking a session tab selects it. The `<` and `>` controls scroll through tabs that do not fit in the toolbar.

Default profiles are PowerShell, Command Prompt and WSL on Windows. Linux uses `$SHELL` (falling back to `sh`), Bash and zsh. Set `GRAPHITE_SHELL` to override all configured profiles, or create `terminal.json` in the application configuration directory:

```json
{
  "defaultProfile": "PowerShell",
  "profiles": {
    "PowerShell": { "path": "powershell.exe", "args": ["-NoLogo"] },
    "Command Prompt": { "path": "cmd.exe", "args": [] },
    "WSL": "wsl.exe"
  }
}
```

Profile entries accept either a path string or an object with `path` and `args`. The legacy `{ "shell": "..." }` format remains supported. `GRAPHITE_SHELL` overrides `terminal.json`; `defaultProfile` selects a named profile when profiles are configured. Empty environment variables are ignored.

## Scope and verification

The terminal uses a native PTY and Alacritty's terminal grid/parser. Automatic server installation, debugging and extension-host support are outside v0.3. Windows automated tests, workspace build and formatting checks are recorded in the roadmap. Native UI interaction remains pending; Linux was not tested in this run.

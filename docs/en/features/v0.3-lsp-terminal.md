# v0.3 — Language servers and integrated terminal

## Language Server Protocol

The app launches user-installed LSP executables over stdio, one server per configured file extension. Processes run outside the window event loop. Open, change, save and close notifications are sent per document, with UTF-16 positions and incremental changes when the server requests them. Diagnostics are stored per tab and stale versioned results are ignored.

The supported interactions are completion (`Ctrl+Space`, then Enter or Tab), go to definition (`F12`), hover (`Ctrl+K`, then `Ctrl+I`), and diagnostic navigation (`F8` / `Shift+F8`). Diagnostics appear in the Problems panel (`Ctrl+Shift+M`). Missing or failed servers report their status while editing remains available.

Create `lsp.json` under the VsCodeShoppe application configuration directory. On Windows this is `%APPDATA%\VsCodeShoppe`; on Linux it is `$XDG_CONFIG_HOME/VsCodeShoppe`, falling back to `~/.config/VsCodeShoppe`.

```json
{
  "servers": [
    {
      "extension": "rs",
      "languageId": "rust",
      "command": "rust-analyzer",
      "args": []
    }
  ]
}
```

`extension` is matched without a leading dot. `command` is the executable name or path, and `args` are passed as separate arguments. Add one entry for each extension/server mapping. The app does not download or install servers.

## Integrated terminal

Toggle the bottom panel with `Ctrl+grave`. Click the Terminal tab to focus it and the Problems tab to inspect diagnostics. The terminal starts in the workspace root, keeps its process alive while hidden, supports ANSI colors, common navigation keys, UTF-8 input, scrollback and resize. Windows defaults to PowerShell; Linux uses `$SHELL`, falling back to `sh`.

To select a different shell, set `VSCODESHOPPE_SHELL` or create `terminal.json` in the same application configuration directory:

```json
{ "shell": "C:\\Program Files\\PowerShell\\7\\pwsh.exe" }
```

The environment variable takes precedence. `terminal.json` contains only the executable path; shell arguments are not configured in this release.

## Scope

The LSP client supports stdio servers, text synchronization, diagnostics, completion, definition and hover. The terminal uses a native PTY and Alacritty's terminal grid/parser. Automatic server installation, debugging and extension-host support are outside v0.3.

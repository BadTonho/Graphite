# Quick open and editor history commands

| Command | What it does |
| --- | --- |
| Quick Open Previous Editor from History (and Quick Open Previous Editor) | Opens a picker with the open editors, most recently used first, with the previous one selected. Enter switches to it. |
| Quick Open Least Recently Used Editor | The same list, oldest first, with the oldest selected. |
| ... in Group variants | List only the editors of the focused group. |
| Accept the Selected Quick Open Item | Accepts the selected item of the open quick open or picker. |
| Open the Selected Quick Open Item in a Permanent Tab | Like accepting, but a file from quick open opens as a permanent tab instead of a preview tab. |
| Close Quick Open | Closes quick open, the pickers and the command palette. |
| Focus Quick Open | Opens file quick open when no widget is open; an open widget already has the keyboard. |
| Quick Open with Modes | Opens file quick open. |
| Open Next / Previous Recently Used Editor (and in Group) | Switch editors in recently used order, the same as the existing Next / Previous Used Editor commands. |

Each document is listed once, even when it is open in several groups. Editors without a file are not listed. The picker shows file name and folder; it does not offer the mode prefixes of other editors (`>`, `@`, `:`).

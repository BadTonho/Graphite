# v0.4 — Git, advanced layout and tools

## Git and source control

Open Source Control with `Ctrl+Shift+G`. The panel lists staged, unstaged, untracked and conflicted paths. Select a row and press `S` to stage, `U` to unstage, `H` to stage its first hunk, `R` to open a conflict, or `C` to enter a commit message. From an editor, `Ctrl+K Ctrl+H` stages the line at the cursor, `Ctrl+K Ctrl+Shift+H` reverts that line, and `Ctrl+K Ctrl+R` reverts the first hunk. File and line decorations appear in the gutter.

The branch name in the status bar opens a local-branch picker. Checkout is refused when the index, worktree or an open editor buffer contains changes; after a successful checkout, open documents reload from disk. Git's own switch operation can still report a race or other checkout error. Conflicts display base/ours/theirs panes. Choose `B`, `O` or `T` to resolve with a side, or `E` to edit the worktree file; saving that file stages the resolution.

Git status updates after editor operations and filesystem notifications. Repository reads, index changes and commits run on worker threads. The current SCM service operates on local worktrees and requires the `git` executable for branch checkout; status, index staging and commits use `gix`.

## Diff view

Run `code -d <left> <right>` to open a two-file comparison. Press `Tab` in the diff view to switch between side-by-side and inline presentation; `Esc` closes it. `Ctrl+Shift+D` compares the active buffer with its HEAD version, including unsaved buffer edits. Diff content currently displays from the beginning of each file and does not provide synchronized scrolling or editable merge hunks.

## Layout and status bar

- `Ctrl+K Z` toggles Zen Mode and fullscreen.
- `Ctrl+K Ctrl+E` toggles an editor centered to a maximum of 80 columns.
- `Ctrl+K Ctrl+O` toggles the right-side Outline. Select a declaration to move the cursor to it.
- The status bar displays the current Git branch, encoding, line ending, indentation and Screencast state. Click the encoding segment to cycle UTF-8, UTF-8 with BOM, UTF-16 LE and UTF-16 BE; click line endings to cycle LF/CRLF; click indentation to convert spaces/tabs. These format changes apply on the next save.

## CLI and local IPC

The `code` executable is installed beside `shoppe-app` and supports:

```text
code .
code path/to/file.rs
code -d left.rs right.rs
code -g path/to/file.rs:12:5
code --wait path/to/file.rs
```

Requests are forwarded to the running editor through a per-user local socket; if no editor is running, the launcher starts one. `--wait` returns after the requested file tabs or diff view close. Windows drive letters are parsed without treating the drive colon as a line/column separator.

## Process explorer and Screencast Mode

Toggle the Process Explorer with `Ctrl+K Ctrl+P`. While open, it reports CPU and memory for the app and its descendant processes, including shells and language servers. Scroll over the panel to view more processes. The panel also displays measured app initialization, window creation and renderer initialization times.

Toggle Screencast Mode from the status bar or with `Ctrl+K Ctrl+S`. An animated ring follows the pointer, and the last key chord appears for 1.5 seconds.

## Verification and scope

Automated coverage includes temporary Git repositories, commits, staging/reverting lines and hunks, conflicts, Unicode diffs, ignored Git files, CLI parsing and local IPC, wait lifecycle, file encodings, process-tree metrics, declaration outlines and layout calculations. Windows `cargo test --workspace` passed (195 tests), `cargo build --workspace` passed, and `cargo fmt --all -- --check` passed. Native-window checks for SCM/merge, layout, CLI, process metrics and Screencast Mode remain pending because the Computer Use native pipe was unavailable; v0.4 is not marked complete until those checks are recorded. Linux is not required for this implementation run and has not been tested.

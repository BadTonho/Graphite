# v0.2 — Editing and customization

## Available interactions

- Select text with the mouse or `Shift` + navigation; `Ctrl+A` selects the buffer. `Ctrl+C/X/V` use the system clipboard; `Ctrl+Z/Y` undo and redo.
- Open files in tabs, switch with `Ctrl+Tab`, and close with `Ctrl+W`. A modified tab asks whether to save, discard or cancel.
- `Ctrl+F` searches the workspace, honors ignore files, and lets you move through matches with Up/Down; Enter opens the selected result.
- `Ctrl+Alt+T` switches and persists the built-in light/dark palette. `Ctrl+Shift+I` imports supported VS Code settings, snippets and JSON themes into the Graphite config directory.
- `Ctrl+Shift+P` filters imported snippet prefixes; Enter inserts the selected match.
- IME committed text is inserted through winit events. The window exposes an AccessKit tree for its editor and tabs.

## Supported imported settings

`editor.fontSize`, `editor.tabSize`, `editor.insertSpaces`, `workbench.colorTheme`, and the supported editor/sidebar/status color keys are applied. Theme `tokenColors` for keywords, functions, types, strings, numbers, comments and variables are mapped to editor syntax classes. Other settings are reported as ignored. Imported files are copied; originals are not modified. Search matches literal text and skips unreadable files. Snippet tab stops are reduced to their default text; choices and variable substitution are not expanded.

Each tab owns a tree-sitter parser and syntax tree. Edits are applied to that tree and highlighting is recomputed from the containing syntax node through end of file; unchanged preceding lines and inactive tabs retain their cached spans. The accessible tree exposes the tab list and editor; assistive technology can activate tabs, focus the editor, replace its value and set a selection.

## Verification

Run `cargo test --workspace` and `cargo check --workspace`. Manually verify input, clipboard, tabs, search, themes, import and screen-reader behavior on Windows and Linux.

# More workbench commands

| Command | What it does |
| --- | --- |
| Move Activity Bar to the Side / Top / Bottom, Hide Activity Bar | Sets the activity bar location; the choice is saved with the profile. |
| Toggle Breadcrumbs / Show Breadcrumbs | Flips or turns on the breadcrumbs. |
| Copy Breadcrumbs Path | Copies the full path of the file in the active editor to the clipboard. Not available for an editor without a file. |
| New Window | Opens another Graphite window on the same workspace. |
| Clear Editor History (and without confirmation) | Forgets the recently used editors, the back and forward navigation history and the list of closed tabs that can be reopened. There is no confirmation step. |
| Revert and Close Editor | Reloads the file from disk and closes its tab. A file with unsaved changes asks for confirmation first and stays open until you answer. |
| Duplicate Editor Group to the Left / Right / Up / Down | Splits a new group on that side with a copy of every tab, keeping the same tab active. |

Breadcrumbs only show the path for now, so the commands that focus, step through or pick items in the breadcrumb bar are not available.

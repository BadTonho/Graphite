# Settings menu

The gear at the end of the Activity Bar opens Graphite's local settings menu. It remains available at the end of vertical and horizontal Activity Bar layouts and is hidden when the Activity Bar is hidden. Use **View → Activity Bar Position → Default** to restore the bar.

The menu opens the command palette, profile chooser, `settings.json`, Extensions, keyboard shortcuts, snippets, and tasks. **Themes** switches between the built-in dark and light themes. File icon and product icon theme choices are shown as unavailable until Graphite supports them. **Layout Density** offers Default and Compact; the selection is saved with the active profile and changes spacing in sidebar lists and panels, independently of Activity Bar size.

The update row reports **Updated**. Graphite does not currently check for or install application updates. Online settings synchronization is not included.

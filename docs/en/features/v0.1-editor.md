# v0.1 — Core Editor

## Features

- Open a folder (`shoppe-app -- <folder>`); `.gitignore`-aware sidebar tree, directories first, `.git` hidden.
- Click a folder to expand/collapse, click a file to open it.
- Text editing: insert, Backspace, Delete, Enter, Tab (displayed as 4 spaces), arrows, Home, End, mouse cursor placement, wheel scrolling.
- Line numbers, cursor, status bar (file, dirty marker, line/column).
- `Ctrl+S` saves the current file.
- Syntax highlighting for Rust, Python, JavaScript and JSON (by extension).

## Where it lives

| Feature | Crate |
|---|---|
| Buffer, cursor, save/load | `shoppe-text` |
| Folder listing | `shoppe-workspace` |
| Highlighting | `shoppe-syntax` |
| GPU drawing and text | `shoppe-render` |
| Window, tree, editor UI | `shoppe-app` |

## Tests

`cargo test --workspace` covers the buffer, workspace listing, atlas packer and highlighter. UI behavior (rendering, input) has been smoke-tested only; it needs manual verification.

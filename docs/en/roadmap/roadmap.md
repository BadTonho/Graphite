# Roadmap

- [x] **v0.1 — Core:** `winit` window, `wgpu` renderer, `cosmic-text`, folder tree, edit/save, tree-sitter highlighting
- [ ] **v0.2 — Editing and customization:** complete selection, clipboard, undo/redo, incremental highlighting, accessibility and IME; add tabs, project search (ripgrep), themes, and import of the supported subset of VS Code themes, snippets and `settings.json`.
- [x] **v0.3 — Language servers and terminal:** implementation and automated coverage complete for LSP diagnostics, inlay hints, Quick Fix, JSON Schema, Sticky Scroll, navigation history, project snippets and multi-session terminal profiles. Native UI verification remains pending.
- [x] **v0.4 — Git and advanced layout:** native Git/SCM, diff and merge tools, `code` CLI, process metrics and Screencast Mode. Windows `cargo test --workspace`, `cargo build --workspace`, and `cargo fmt --all -- --check` passed on 2026-11-09. Native UI checks were explicitly waived; no manual UI validation is claimed. Linux was not tested.
- [x] **v0.5 — Extensions and automation:** Items 4 (universal command palette), 8 (pinned Code OSS host and VSIX), 9 (Tasks), 15 (workspace trust), 16 (profiles) and 18 (Emmet) are complete. The Windows portable runtime passed the local API matrix and the public Open VSX sample. See [v0.5 validation](../features/v0.5-extensions-automation.md).
- [ ] **v0.6:** DAP sessions, restricted extension webviews, Markdown/image previews, VSIX Test Explorer and local process ports. Initial implementation is present; full feature acceptance and Windows/Linux native validation remain open. See [v0.6 implementation and limits](../features/v0.6-debug-webviews-testing.md).
- [ ] **v1.0+:** broaden the API guided by the compatibility suite; GitHub (`octocrab`); WASM plugins where compatibility falls short

v0.1 verification: the Rope buffer loads and saves UTF-8 in chunks, saves through a temporary sibling file, and preserves its path and dirty state on failure. Incremental tree-sitter parsing reads Rope chunks directly. Tests cover large Unicode files, I/O failures, nested ignore rules and incremental highlighting. The Windows workspace build and automated tests pass; interactive window, GPU recovery and Linux verification remain outstanding.

v0.2 progress: multiple cursors, document find and replace, line actions, syntax selection, fuzzy file opening, ripgrep-based project search with unsaved-document overlays, split groups sharing documents, visual wrapping, configurable keybindings, indentation, rulers, read-only patterns and VS Code settings/theme/snippet import have implementations and automated coverage. Windows `cargo test --workspace` passes (139 tests) and `cargo build --workspace` passes. Clipboard behavior now has isolated Unicode, multi-cursor, undo, read-only and backend-failure tests. The implementation review found no other missing phase 2 feature. Interactive window, clipboard, IME, screen-reader and rendering checks remain outstanding because the native Computer Use pipe was unavailable in this session. Linux was not tested in this run. The implementation is complete; keep the phase open until interactive verification is recorded.

v0.2 acceptance: per-tab document/cursor/selection/scroll/dirty state; Unicode-safe editing and history; project search honoring workspace exclusions; source-preserving import with clear errors for invalid or unsupported items; incremental highlighting; accessibility and IME integration. Verify key flows on Windows and Linux and cover buffer, search and import with unit tests. Import applies only supported settings and does not promise full VS Code compatibility.

v0.3 progress: LSP servers and JSON Schema validation run on background workers. Problems combines language-server and schema diagnostics; F8/Shift+F8 traverse the list, Quick Fix applies workspace edits, and inlay hints are rendered. JSON/JSONC supports local or HTTPS schemas, cached remote retrieval, property/value completions and schema diagnostics. Sticky Scroll uses tree-sitter declarations; cursor history, MRU tabs and closed-tab recovery are available. The terminal supports multiple sessions, split panes, named profiles and profile arguments while preserving `shell` and `GRAPHITE_SHELL` precedence. Project `.vscode/*.code-snippets` files support language scopes and project-over-global prefix precedence. Windows `cargo test --workspace`, `cargo build --workspace` and `cargo fmt --all -- --check` pass. Native window checks are still pending; Linux was not tested in this run. Phase 2 interactive verification remains the next manual gate.

v0.3 acceptance: configured server processes stay off the UI thread and shut down with the app; document synchronization and diagnostics are version-aware and use UTF-16 positions; completion, definition, hover, inlay hints, Quick Fix and diagnostic navigation work per tab; the terminal supports multiple PTY sessions, profile arguments, ANSI parsing, keyboard input, resizing and scrollback. JSON/JSONC schemas resolve from local paths or HTTPS and report failures without interrupting editing. Sticky Scroll, cursor history, MRU/closed tabs and scoped project snippets are covered. Automated Windows checks pass; native interactive verification remains pending.

v0.4 progress: the native SCM service reports staged, unstaged, untracked and conflicted files; supports commits, file and line/hunk staging or reversion, branch checkout guarded by a clean-worktree and clean-editor-buffer check, open-document reload after checkout, gutter decorations and three-way conflict resolution. Diff view supports two files and the active buffer versus HEAD, including unsaved edits. The layout adds Zen Mode, an 80-column centered editor and a navigable Outline as the Secondary Side Bar view. The status bar selects UTF-8/BOM/UTF-16, LF/CRLF and indentation. The `code` launcher supports folder/file opening, `-d`, `-g` and `--wait` through per-user local IPC. Process metrics include the app and descendant processes; startup timing and Screencast Mode are available. Windows workspace tests, build and formatting checks passed on 2026-11-09. Native UI verification was waived and is not claimed; Linux was not tested.

v0.4 acceptance: isolated tests cover Git status/commit/partial changes/conflicts/diffs, CLI parsing, local IPC and wait lifecycle, file formats, layout, line decorations, process metrics and shortcut handling. Windows `cargo test --workspace`, `cargo build --workspace` and `cargo fmt --all -- --check` passed on 2026-11-09. By user decision, native-window verification is waived for phase closure; it was not performed. Linux was not tested.

v0.6 progress: initial DAP stdio sessions, trusted launch/attach configuration, breakpoint fields, native WebView IPC/CSP, Markdown and PNG previews, VSIX TestController bridge, and Graphite-owned local process inspection are integrated. `cargo build --workspace --offline` and `cargo fmt --all -- --check` pass on Windows. Full workspace tests report 256 passed, 48 failed and 2 ignored; isolated Phase 6 service tests pass. See the feature record for current gaps. Linux, X11/Wayland and native UI validation have not been performed.
